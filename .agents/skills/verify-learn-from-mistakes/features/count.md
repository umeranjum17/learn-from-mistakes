# Count

## Sub-features
Separate sources, collapse duplicates, honor occurrences, disclose unread records.

## How to get to it (user POV)
After ingest, run `learn-from-mistakes-axi count`; provide `--labels` for judged records.

## Driving it with the public CLI
Inspect helper count logs and the existing e2e journeys: unlabelled count is
13 before labels; labelled count is 13/13 after. Memory kill has 4 incidents in
3 records; cache lock has 3 incidents in 4 records (one duplicate collapsed).
Agent exit has 4 store rows across 3 days; log and store totals are never added.
A failed store row with no timestamp counts as a row but never as a day: the
`npm test` journey moves three matching rows onto one day and blanks the fourth,
so the store shows 4 rows on 1 day and the cause is not repeated at `min_days: 2`.

## Gotchas
The `other` group cannot qualify as repeated. Private labels are caller-supplied,
not generated by verification, and synthetic totals do not apply to private data.
