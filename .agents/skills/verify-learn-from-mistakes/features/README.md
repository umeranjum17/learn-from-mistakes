# CLI feature map

| Feature | Public drive | Expected evidence |
| --- | --- | --- |
| [Ingest](ingest.md) | `learn-from-mistakes-axi ingest` | source counts, `sha256` content identity per source (store digest stable across mtime, changes with rows) and retained state; input hashes unchanged |
| [Project state dir](state.md) | `learn-from-mistakes-axi ingest`/`change applied` with no global config, in a git project | `.lfm/` beside the config with a `*` `.gitignore`, clean `git status`, separate state for same-named projects, `state_root` override, an owner `.gitignore` that ignores all of `.lfm` left byte-identical, a deficient one refused |
| [Count](count.md) | `learn-from-mistakes-axi count` before/after labels | separate source totals, duplicate/occurrence arithmetic, unread coverage |
| [Report and errors](report.md) | `learn-from-mistakes-axi report`, bare `learn-from-mistakes-axi`, existing negative journeys | after a retro with labels, `labels_from: run <id>` with the run's counts, each finding's cause, count and days, and its summary as one TOON `finding:` line (JSON never has the summary), else `labels.jsonl`; real refs; bad input/empty exits, proposal rules (repeated causes only, target/owner, at most five), no fabricated coverage; every rejection is one `error:` line plus `next:`, never the usage block |
| [Applied-change ledger and export](change.md) | `learn-from-mistakes-axi change applied [--metric --tripwire --kind] [--what --why]` (`--proposal`: [propose.md](propose.md)), `learn-from-mistakes-axi changes [--json]`, `learn-from-mistakes-axi report --json`/`--full` | append-only bytes, per-cause counts and ids, `lfm-changes.v1` with stable ids, `metric`/`tripwire`/`kind` (defaults for old lines) and owner what/why; a bad `--tripwire` exits 2 with the allowed form; what/why and canary absent from the report |
| [Machine surface](surface.md) | `--help`, `--version`, bare command, `--json`, `--full`, TOON default | behavior asserted by `test/cli.test.mjs`: valid TOON equal to the `lfm-report.v1` JSON, non-content ids-only `--full`, a private canary absent from every output and stderr; the helper only captures evidence |
| [Config v2 and source registry](config.md) | `.learn-from-mistakes.yaml` with agent and v2 keys and the global `$LFM_HOME/config.yaml` (same config shape as no-mistakes), then `learn-from-mistakes-axi retro --foreground` | v1 configs unchanged; every key loads (9 completed steps); a bad key or value such as `agent: 3` exits 2 naming the key, and a global-only key in the project file does too; sources read through `src/sources/<type>.mjs` |
| [Agent sessions](sessions.md) | `sessions: { type: sessions }` in the config, then `learn-from-mistakes-axi retro --foreground` | only this repo's Claude Code, Codex and OpenCode sessions (dir, subdir, worktree) counted, subagent files and threads read, OpenCode stores byte-identical, own runs (`.lfm/` cwd, `lfm-run:` marker, `invocations` ids) and old files skipped; `events` rows with signals; run output `sessions` and `skipped` (numbers in [metrics.md](metrics.md)); planted keys redacted, never in `.lfm/` or output |
| [GitHub PR source](github.md) | `prs: { type: github }` in the config (or `init` in a GitHub clone), then `learn-from-mistakes-axi retro --window 30d --foreground` | PRs merged in the range read through `gh api graphql` (paged, stops before the range, one row per PR), one `records` row each with redacted title and body (none with `excerpts: off`) and `data`; `merged`, `first_pass`, `p50/p90_hours_to_merge`, `rework_ci`, `rework_other`, `reverted`, `escaped` for both windows; a missing or logged-out `gh` or a non-GitHub origin exits 2 with the fix, never the origin URL; the fake-`gh` journeys in `test/github.test.mjs` |
| [done-done source](done-done.md) | `proof: { type: done-done, apps: [<app>] }` in the config, then `learn-from-mistakes-axi ingest`, `doctor`, `retro --foreground` | one record per failed step of a failed, inconclusive or overridden verify run (day, step, short redacted reason, the run file as `ref`); passed, cancelled and unfinished runs none; an app with no runs is a doctor warn with the fix; a run file of another schema exits 2 with `update learn-from-mistakes-axi`, never skipped inside the window; bad steps exit 2 with `done-done status --run <id>`; the journey in `test/cli.test.mjs` |
| [Metrics step and windows](metrics.md) | `learn-from-mistakes-axi retro --foreground`, `causes.<c>.match` on a sessions or gate source, `targets:` | a `metrics` step and table: each source's numbers for `current` and `previous`, `cause_count:<cause>` from tagged events and records, `n/a` (NULL) where nothing measures; each target with `met`/`missed` (`n/a` for an n/a number); a match rule tags exactly the planted events, with `excerpts: off` too |
| [Follow-up step and verdicts](followup.md) | `learn-from-mistakes-axi change applied --metric --tripwire --kind`, then `learn-from-mistakes-axi retro --foreground` twice | a `followup` step and `followups` table: per change `before`/`after` (unrounded, NULL for n/a), `tripwire` and a code verdict `keep`, `fix`, `rollback`, `delete` or `no-data`; the second retro deletes a flat rule change (with or without a tripwire) and rolls back a second miss; a change older than both windows still gets its before number |
| [Bundle step](bundle.md) | `learn-from-mistakes-axi retro --foreground`, then `.lfm/runs/<id>/bundle.md` | metrics, follow-ups, signal clusters and unlabelled records, each with an id and refs; planted keys, another repo's gate rows and (with `excerpts: off`) all record text never in it; `caps.bundle_chars` holds with a dropped line; the gate source reads only this repo's rows |
| [Analyse step and agent harness](analyse.md) | `learn-from-mistakes-axi retro --wait 15m`, `logs --step analyse` | the worker's `findings` and `labels` rows, counted by the run's report, and one `invocations` row per call (tokens, session, exit status); a ref to no bundle item is a logged `problem:` and dropped; bad JSON twice exits 1 and `logs --step analyse` shows the validation error; `caps.invocations` stops a run; an ended run leaves no agent process group |
| [Propose and check steps](propose.md) | `learn-from-mistakes-axi retro --wait 15m`, `status`, `logs --step check`, `change applied --proposal <run>:<n>` | the worker's `proposals` rows and a `followups.reason` for each follow-up that is not keep; 6 fixes that follow the rules give 5 kept, ranked and numbered; a cause that did not repeat and no tripwire are logged `problem:` lines; `status` lists the kept `fixes`; `--proposal` copies cause, metric and tripwire into the ledger, a fix not kept exits 2 |
| [Verify step (the judge)](verify.md) | `learn-from-mistakes-axi retro --wait 20m`, `logs --step verify` | one `invocations` row on the judge (`judge_agent`, never the worker); `verdict` and `judge_note` on each `findings` and `proposals` row (`confirmed`, `weakened` or `refuted`); a fake judge that refutes claim `p2` marks the second proposal row `refuted`; the log shows ids and verdicts only |
| [Saved runs](run.md) | `learn-from-mistakes-axi retro [--wait <time> \| --foreground]`, `status`, `runs`, `attach`, `logs --step <name>`, `abort`, `rerun [--resume]` | a completed run with 9 step rows in `.lfm/lfm.sqlite`, shown by `status` and `runs`; its `result` shows the counted causes and each worker finding on one line, or `result: the worker labelled no record and named no finding` with `next:` the analyse log; `.lfm` git-ignored; a failed step exits 1 with its error saved; a detached run outlives its shell; a killed worker shows `interrupted` and `rerun --resume` completes it without running the completed step again; `attach` prints each step's lines and states then exits 0 at the end; `logs --step collect` prints that step's lines; `abort` ends the worker and gives `cancelled`; a plain `rerun` starts a new run |
| [Agent runners](agents.md) | `learn-from-mistakes-axi agents [--json]`, `agents --test <runner>`, `agents --test byokit:<route>` | usable runners with version, tools, login file names (never contents), model from `agent_config` (the user's; no defaults), only the configured agents listed, worker and judge by the identity rule (a clash exits 1), an unset role asked (a terminal) or exit 2 with the ask; `--test`: a reply, or the real error; argv, timeout kill, pipe wait, write refusal and retry asserted by `test/runners.test.mjs`; `byokit:chatgpt` answers through BYOKit's stand-in with the machine-store sign-in (signed out: exit 1 and the fix), `byokit:opencode-go` answers a Responses stand-in with the key from `OPENCODE_API_KEY` held in memory (no key: exit 1 and the fix), other names refused, the doctor hook's sign-in state and install command |
| [init: config and detection](init.md) | `learn-from-mistakes-axi init [--agent <agent> [--model <model>]] [--judge-agent <agent> [--judge-model <model>]] [--no-excerpts]` | project config written once (a second init is byte-identical, `already set up` with gaps), the global `config.yaml` written once and kept, the agents and models the user chose saved (none chosen: a gap and the ask `next:`, a terminal is asked), the global file all commented, sources from the registry `detect()` hooks, `.lfm/` git-ignored; a judge on the worker's identity is a gap with the fix or, as a flag, exit 2 |
| [doctor](doctor.md) | `learn-from-mistakes-axi doctor [--live] [--json]` | one `ok/warn/fail` line per check with `fix:` under each that is not ok; a missing source, a premium model on each role and a judge on the worker's identity are 4 fails and exit 1, exit 0 after the fixes; an unset agent exits 2 with the ask; login probes (`codex login status`, `opencode auth list`, `pi auth check --no-refresh`) print no credential text; a missing skill or sign-off off PATH is a warn |
| [Package install](package.md) | helper `--package`; `npm pack` + fresh-prefix install | manifest carries the bin, metadata and standalone skill; the installed bin drives the report and the export, and passes the e2e suite |
| [Agent skill](skill.md) | `npm run build:skill -- --check`; local-registry `npx -y learn-from-mistakes-axi`; `npx skills add` + clean agent session | check passes then fails on a one-char edit; npx help/guide/journey; the agent loads the skill unprompted and reports a repeated cause |

Run the helper from `../SKILL.md`; reuse `test/cli.test.mjs`, `test/runners.test.mjs`, `test/init.test.mjs` and `test/github.test.mjs`, never duplicate their
journeys in a new test file. Synthetic expectations apply only to `examples`.
The package install journey resolves the declared npm dependencies and may
touch the registry; the default journey starts no network.
